# Pixel Pulse

Pixel Pulse is a responsive image-search application built with HTML, CSS, and JavaScript. It will allow users to search for images based on their favourite topics.

I chose a forest-green and cream colour theme to create a calm and natural appearance. I added category suggestion chips to help users discover popular topics quickly.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to run

Open index.html in your browser.
